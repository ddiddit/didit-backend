==== 회고 품질 피드백

결과 화면 하단의 "이번 회고 어땠나요? (선택 사항)"에서 대화와 결과에 대한 의견을 수집합니다.
평가 및 사유 문구는 앱에서 표시하며, 백엔드는 아래 코드를 사용합니다.

[cols="1,1,2",options="header"]
|===
|평가 |사유 코드 |표시 문구
|HELPFUL (도움이 됐어요) |CORE_IDENTIFIED |핵심을 잘 짚어줬어요
|HELPFUL |DEEP_QUESTIONS |질문이 깊었어요
|HELPFUL |WELL_ORGANIZED |정리가 잘 됐어요
|NEEDS_IMPROVEMENT (다른 방향이 필요해요) |SIMPLE_QUESTIONS |질문이 너무 단순했어요
|NEEDS_IMPROVEMENT |INACCURATE_CONTENT |내용이 부정확해요
|NEEDS_IMPROVEMENT |MISSED_CONTEXT |맥락을 못 따라왔어요
|두 평가 공통 |CUSTOM |직접 입력
|===

* 평가는 둘 중 하나만 선택합니다. 사유는 선택 사항이며, 직접 입력을 포함해 최대 3개입니다.
* 같은 사유를 중복 선택하거나 반대 평가의 사유를 선택하면 400 오류입니다.
* CUSTOM 선택 시 comment는 공백이 아닌 내용이 필수이며, 입력값 기준 최대 500자입니다.
  길이는 문자열의 UTF-16 코드 단위 기준이며 이모지는 2개 이상으로 계산될 수 있습니다.
* CUSTOM 미선택 시 comment는 생략하거나 null로 전송합니다. 빈 문자열도 허용하지 않습니다.
* 본인 소유의 완료되고 결과가 생성된 V1/V2 회고만 평가할 수 있습니다.
* 회고당 피드백 하나를 유지합니다. PUT 재제출은 기존 평가와 사유, 의견을 모두 교체합니다.
  평가 방향 변경 시 앱에서는 기존 사유와 의견을 초기화하고 새 선택값을 전송합니다.
* 피드백은 회고 결과를 변경하거나 재생성하지 않습니다. AI 개선을 위한 의견으로 수집합니다.
* 회고 삭제 후에도 피드백을 보존합니다. 삭제된 회고에는 사용자 조회·등록·변경을 허용하지 않습니다.
  앱에서 회고 삭제 후에도 피드백을 보존한다는 안내가 필요합니다.
* 회고 원문·제목·결과와 AI 버전은 피드백에 복사하지 않습니다. 관리자 조회·집계 기능은 후속 작업입니다.

===== 피드백 등록·변경

최초 제출과 변경 모두 200 응답이며, 회고당 동일 피드백 ID를 유지합니다.
같은 내용의 재전송은 추가 행을 생성하지 않습니다. 동시 변경은 서버에서 처리된 마지막 요청의 값이 남습니다.
타인·삭제·존재하지 않는 회고는 404, 미완료·결과 미생성 회고는 400을 반환합니다.
