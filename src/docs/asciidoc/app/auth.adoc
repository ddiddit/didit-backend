== 소셜 로그인 v2

`POST /api/v2/auth/social/login`은 KAKAO, GOOGLE, APPLE 로그인에 공통으로 사용합니다.
각 제공자에 맞는 `credentialType`과 `credential`을 전달합니다.

`redirectUri` 는 인가 코드 교환에 필요한 제공자만 전달합니다. 현재 Kakao의 `AUTHORIZATION_CODE` 요청은
인가 코드 발급에 사용한 callback URI를 `redirectUri`로 함께 전달해야 합니다.

응답의 `data.status`가 `AUTHENTICATED`이면 발급된 서비스 토큰을 사용합니다. `EMAIL_VERIFICATION_REQUIRED`이면
아래 이메일 인증번호 발송과 이메일 인증 완료 API를 순서대로 호출합니다.
