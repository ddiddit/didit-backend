= 회고 V1 API (Legacy)

[WARNING]
====
구버전 앱 호환용 회고 API입니다. 신규 회고는 회고 V2 API를 사용해주세요.
====

[NOTE]
====
표기 기준입니다.

* `[Legacy]`: V1 플로우에서만 사용하는 API입니다.
* `[V1·V2 공통]`: 경로는 V1을 유지하지만 V2 회고의 결과·관리 화면에서도 사용하는 API입니다.
* `[Deprecated]`: 신규 연동에서는 V2 대체 API를 사용해야 하는 API입니다.
====
